# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version: be respectful, assume good faith, focus on the work. Harassment,
discrimination, and personal attacks have no place here.

If something happens that shouldn't, report it by opening a private discussion or
contacting the maintainer directly via GitHub.
